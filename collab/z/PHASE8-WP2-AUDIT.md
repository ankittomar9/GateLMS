## 3. Recorded deviation & advisories (non-blocking)

- **D-1 — concept cards omit the "one-line plain explanation" (§7 Task 3 letter).** The spec's card anatomy lists label, one-line plain explanation, coverage chip, mapped count, lesson state. The taxonomy data model has **no description field** (`concept_tags` = slug/label/topic only; SPEC §6.1 defines exactly slug+label), and adding one would violate the spec's own §5.2 V17-minimalism rule. Implemented card = label + slug + coverage chip + counts + lesson state. **Accepted — the data model constraint wins; the explanation arrives naturally in WP2's lesson viewer (motivation section).**
- **A-1 (MEDIUM-LOW, carried pattern from S-1): API-level `force=true` on lesson generate is student-callable.** `POST /journey/concepts/{slug}/lesson/generate?force=true` has no `@PreAuthorize`; a student can force-regenerate and overwrite a shared lesson, resetting an ACCEPTED unit to a fresh DRAFT (content replaced, coverage EXPLAINED→MAPPED until re-curated). Mitigations: per-user primer-bucket quota, honest AI-GENERATED/DRAFT badge, admin re-accept path, UI gates force to admin. Mirrors the M2/S-1 primer-force situation exactly (my S-1 advisory A-1, still open there too). **Recommend a small fixup: `@PreAuthorize` the `force` path (or reject force when `status == ACCEPTED`) for BOTH lessons and primers.**
- **A-2 (LOW): hardcoded fallback model label `"gemini-3.8-flash"`** in `ConceptLessonService` (`generatorModel` metadata only, never used for routing). Diverges from the configured default (`gemini-3.5-flash` family). Cosmetic metadata; align when touched.
- **A-3 (LOW): `backend/src/test/resources/docker-java.properties`** (`api.version=1.44`) — machine-specific Docker/Testcontainers compatibility pin committed to the repo. Harmless (API 1.44 widely supported), but it is environment config in version control; consider moving to local/CI-specific config or documenting it.
- **A-4 (carried, wider): N+1 tag lookups** — the optional-repo per-question `findSlugsByQuestionId` pattern now also fires in question-list paths; still pilot-scale tolerable. Batch-fetch during scale-out (unchanged disposition from WP1 A-3).
- **N-1 (note):** trap count 2–4 is prompt-enforced, not hard-validated (not a binding acceptance rule; acceptable).
- **N-2 (note):** lesson generation happy-path is unit-tested (mocked AI, force=true persists DRAFT) and the failure path is IT-tested; no mocked-success IT — acceptable coverage combination.
- **N-3 (note):** `ConceptLessonViewer.tsx` at 602 physical lines vs 568 code-only — keep an eye on it at the next touch; extract sub-sections if it grows.
